ATUALIZAR GITHUB PAGES
1. Exporta primeiro um Backup ZIP dentro da versão anterior.
2. Descompacta esta pasta e envia os ficheiros para a raiz do MESMO repositório GitHub Pages.
3. Inclui app.js, index.html, sw.js, manifest.webmanifest, ícones e as 20 imagens ajudas-avelino-XX.webp.
4. Confirma as alterações e volta a abrir o mesmo endereço. Se necessário, fecha e reabre a PWA.
5. Verifica os registos e o modo offline, e conserva sempre uma cópia ZIP.

Não publiques o backup agrícola no repositório público.
Os dados no IndexedDB pertencem ao endereço/origem da aplicação; não migram automaticamente.
